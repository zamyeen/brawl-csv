What can I import? Instructions for older history

Moving from another browser? In the old browser, open this website, choose Export history, then select that downloaded .json file here with Import history. Existing records are merged without duplicate snapshots.

Older saved progress: If you already used the Resource Value dashboard in this same browser, earlier snapshots should appear automatically. If you only have the old browser-storage value under brawl-csv:resource-history:v1, save that JSON text to a .json file and import it directly. The importer accepts that older format too.

Required for raw older data: A JSON object with entries named #PLAYERTAG:owned or #PLAYERTAG:all. Each entry is an array of snapshots with an ISO-8601 timestamp and nonnegative whole-number coins and points. For example:

{
  "#2P0Y8Q9:owned": [
    {
      "timestamp": "2026-11-01T12:00:00.000Z",
      "coins": 50000,
      "points": 20000
    }
  ]
}

The regular Download JSON player-account export is not a history backup and cannot be imported here. You cannot reconstruct past progress if no earlier snapshots were saved. Maximum import file size: 2 MB. History stays on this browser unless you export it.
